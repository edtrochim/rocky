# Gh Greenhouse

## Definition (verbatim, FAO LCLR)

A structure built in order to regulate the climate/environment; therefore, the plants inside can thrive. Human-made structures which galvanize iron steel used as the pillar/bone and plastic sheets to wrap up. The size ranges, up to 33 meters by 30 meters. Greenhouses are usually used in the winter season for cultivation.
