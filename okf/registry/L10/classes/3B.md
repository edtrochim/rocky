# 3B Marginal irrigated crops

## Definition (verbatim, FAO LCLR)

Agricultural lands in a marginal agricultural area, usually devoid of active fields. It also represents the non-active portion of a karez system. The fields, when in use, are predominantly irrigated herbaceous crops.
