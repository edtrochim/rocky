## Rationale

The source gives only the title 'Savanna Formation' under level-1 'Forest' (code 1). A savanna is a woody stratum of trees over a continuous herbaceous stratum, so the decomposition is two strata: trees (fixed) above graminoids and forbs (fixed). MapBiomas files this class under Forest formation, which implies the tree stratum is what defines it; Argentina, Bolivia and Ecuador use code 4 for 'Open forest(s)', Peru for 'Dry forest', Venezuela for 'Wooded savanna', Paraguay for 'Open Natural Woodlands', so the discriminating attribute against sibling 3 'Forest Formation' is tree cover, and against 12 'Grassland' the fixed presence of trees. No cover threshold is stated anywhere in the source, so covers are left empty. Registry example L45 Sa (Tree savanna) sets trees at 4-20 % and herbaceous at 40-100 %, and L45 Sh (Grass savanna) has a woody stratum as conditional; this class is closer to Sa but Brazilian usage of 'Savanna Formation' (Cerrado) usually means denser tree cover than 20 %, so the L45 thresholds are not transcribed.

## Open questions

- Whether shrubs are part of the class (Cerrado sensu stricto has a shrub layer) or belong to 10 'Herbaceous and Shrubby Vegetation'.
- Same code 4 means 'Open forest' in Argentina, Bolivia and Ecuador, 'Dry forest' in Peru, 'Wooded savanna' in Venezuela: decide whether these are the same cover with different thresholds or different covers.
