# Brazilian phytogeographic vocabulary (IBGE vegetation classification, Cerrado / Caatinga / Restinga terms)

IBGE (Brazilian Institute of Geography and Statistics), as used by MapBiomas · scientific_convention · Brazil 

## Effect on classes

Names 'Forest Formation', 'Savanna Formation', 'Wooded Sandbank Vegetation', 'Herbaceous Sandbank Vegetation' and 'Hypersaline Tidal Flat' are Brazilian vegetation-typology terms (formações florestais, savânicas, restinga, apicum). They are typology names, not cover thresholds, which is why code 4 'Savanna Formation' sits under Forest in Brazil while neighbours use code 4 for 'Open forest'. Likely instrument; the legend sheet does not cite IBGE explicitly.
