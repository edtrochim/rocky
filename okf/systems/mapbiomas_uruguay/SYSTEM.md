## Notes

The published Uruguay Collection 3 legend lists Agriculture as code 19, but every Uruguay raster in this dataset encodes agriculture as code 18 and contains no pixels with value 19. Code 18 is therefore included with the pan-MapBiomas standard Agriculture color.
