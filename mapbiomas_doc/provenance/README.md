# Provenance — legends, harmonisation tables and build scripts

The machine-readable tables the catalog README refers to, and the scripts that build this catalog from the raw MapBiomas country exports. `legends.json` holds the official legend for each of the ten countries as transcribed from the national Legend Code PDFs. `observed_classes.json` holds the class histogram of every source raster - the evidence used to establish which MapBiomas collection each country-year belongs to. `harmonization.csv` is the three-tier crosswalk documented in the catalog README. This collection holds no raster data.
