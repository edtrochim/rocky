# Reproducing this catalog

`README.md` in this directory is generated by `portolan readme` and lists the
files. This file explains what each one is and how to rebuild the catalog from
the raw MapBiomas country exports. It is hand-written and not regenerated.

## Reference tables

| file | what it is |
|---|---|
| `legends.json` | Official MapBiomas legend for each of the ten countries — class code, English name, hex colour — transcribed from the national "Legend Code" PDFs. Each entry records the source URL, and a note where a published legend is internally inconsistent. |
| `observed_classes.json` | Class-code histogram for every source raster (1-in-16 sample). The evidence used to pin each country-year to a MapBiomas collection and to find the Chile 2022 mosaic artefacts. |
| `harmonization.csv` | The three-tier harmonisation: one row per country and class code, with the Tier A (level-1), Tier B (pan-MapBiomas) and Tier C (Brazil Collection 10) target, whether the Tier C fold is lossy, and why. The table the catalog README documents. |
| `crosswalk.csv` | The *original* crosswalk from `extract_hansen_mapbiomas_v16.Rmd`, reproduced as-is with an audit column showing where it silently drops codes. Kept for comparison with `harmonization.csv`. |
| `gaps.json` | The audit behind `crosswalk.csv` — per country, which observed codes the original crosswalk failed to map. |

## Scripts

| script | what it does |
|---|---|
| `make_cogs.py` | Converts the raw country GeoTIFFs to COGs: uint8 cast (verified lossless at full resolution first), DEFLATE + predictor 2, 512×512 tiles, `mode`-resampled overviews, the country's official colour table, and class names as `CLASS_<code>` TIFF tags. Resumable — a valid existing COG is skipped. Pixel values are never reclassified. |
| `relayout.py` | Moves each COG into the `collection/<item_id>/<item_id>.tif` layout Portolan's metadata scanner requires. |
| `harmonization.py` | Builds `harmonization.csv`. Holds the class hierarchies, collision resolutions and lossy folds as data, with the reasoning for each in comments. |
| `crosswalk.py` | Reproduces the original Rmd crosswalk and audits it against `observed_classes.json`. |
| `write_metadata.py` | Generates the catalog and per-collection `.portolan/metadata.yaml` from the tables above. `portolan readme --recursive` renders these into the README files. |
| `finalize_stac.py` | Repairs and enriches the STAC that `portolan add` produces: per-item dates, band definitions moved onto the data asset (STAC 1.1 requires this; Portolan writes them into item properties, which the schema rejects), the `classification` extension, licence, titles, POSIX `href` separators. |
| `make_thumbnails.py` | Renders one thumbnail per collection from the COG's own overviews and embedded colour table, and registers it as a STAC collection asset. |
| `fix_versions_freshness.py` | Clears a `portolan check` false positive: `portolan add` and the freshness reader disagree on the field names in `versions.json`, so every raster reports STALE right after a successful add. Writes the real current values under the names the reader expects. |
| `register_extra_assets.py` | Registers `thumbnail.png` in each collection's `versions.json` and turns this `provenance/` directory into a real Portolan collection, so `portolan push` ships the thumbnails and these files instead of leaving them behind. |

## Order of operations

```bash
python provenance/make_cogs.py             # writes COGs (hours; resumable)
python provenance/relayout.py
python provenance/harmonization.py

portolan add mapbiomas-<country>           # once per country

python provenance/write_metadata.py
python provenance/finalize_stac.py
python provenance/make_thumbnails.py
python provenance/fix_versions_freshness.py
python provenance/register_extra_assets.py
portolan readme --recursive
portolan check                             # metadata + geo-assets pass
```

`portolan add` regenerates `collection.json`, the item JSONs and `versions.json`
from scratch, so everything after it must be re-run after any `add` or the
corrections are lost.

## What is not reproducible from here

The raw country GeoTIFFs themselves. They were exported per country and year
from the MapBiomas platform (mapbiomas.org), which is the authoritative source
and the place to get newer collections. `make_cogs.py` reads them from `SRC_DIR`
at the top of the file — point that at your own copy.
